Los libros no terminan en la última página, comienzan un nuevo viaje.

LibroViajero es una plataforma diseñada para fomentar la circulación de libros físicos, permitiendo que cada ejemplar encuentre nuevos lectores y continúe su recorrido.
Cada usuario podrá registrar sus libros y poner sus ejemplares a disposición de la comunidad. A través de una identificación única, será posible conocer su disponibilidad, ubicación y seguir su recorrido a medida que pasa de un lector a otro.
La iniciativa busca promover el acceso a la lectura, la reutilización de libros y el consumo responsable.

Accesos rápidos a la API (GET)

Usuarios

Lectores que registran ejemplares físicos.

  • /api/usuarios

Libros

Catálogo general, filtros y búsqueda por título.

  • /api/libros
  • /api/libros?genero=Novela
  • /api/libros?titulo=rayuela

Ejemplares

Copias físicas, estado y ubicación actual.

  • /api/ejemplares
  • /api/ejemplares?estado=disponible
  • /api/ejemplares?ubicacion=CABA

Listado completo de endpoints

Método Endpoint Descripción
GET /api/usuarios Listar todos los usuarios
GET /api/usuarios/:id Obtener un usuario por ID
POST /api/usuarios Crear un nuevo usuario
PUT /api/usuarios/:id Actualizar un usuario existente
DELETE /api/usuarios/:id Eliminar un usuario (si no tiene ejemplares asociados)
GET /api/libros Listar libros (acepta filtros ?titulo=, ?autor=, ?genero=)
GET /api/libros/:id Obtener un libro por ID
GET /api/libros/:id/ejemplares Listar los ejemplares de un libro (acepta ?estado=)
POST /api/libros Crear un nuevo libro
PUT /api/libros/:id Actualizar un libro existente
DELETE /api/libros/:id Eliminar un libro (si no tiene ejemplares asociados)
GET /api/ejemplares Listar ejemplares (acepta filtros ?estado=, ?ubicacion=, ?codigo=)
GET /api/ejemplares/:id Obtener un ejemplar por ID
POST /api/ejemplares Registrar un nuevo ejemplar físico
PUT /api/ejemplares/:id Actualizar estado, ubicación o datos de un ejemplar
DELETE /api/ejemplares/:id Eliminar un ejemplar por ID
