## Aplicaciones Hibridas

## Parcial 1 - Libro Viajero

Libro Viajero: Permite administrar un catálogo de libros y registrar ejemplares físicos asociados a cada obra y a su propietario original, facilitando consultar su disponibilidad y ubicación actual mientras circulan entre lectores.
